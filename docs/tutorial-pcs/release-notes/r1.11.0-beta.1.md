# v1.11.0-beta.1 (Sep 26, 2026) 🎬

### New Features

#### Custom Position Sounds
- Added new sound set for custom positions.
- Toggle on custom position menu alone without sound override menu will make them use this new sound set.
- This new feature gives you additional sound slot. So you can change this without needing to replace the main sounds.

#### New Audio Layer
- Brought back the legacy feature like fluid squish that randomly plays on top of certain lust level and heavily plays when orgasm. However, because of VRChat audio limitation, this mean those will temporary stop playing during the squirt (~1.5 secs) and when voice menu is activated.

### Changes & Fixes

#### PCS Installer Tool now works like a non-destructive tool
- PCS will automatically be installed to your avatar on build, so you can change the settings at anytime without needing to re-open the installer tool and re-apply.
- Just add it to your avatars, change the settings, and leave it. Each installer will also bond to a specific avatar, so no confusing setup when you have many avatar variants in the scene.
- The original Apply button is still available as the new `Pre-Install` button. This button will pre-process and permanently generate PCS assets like usual, ready to be modified or exported with your avatar.

:::info Note for Creators
The PCS installer now operates non-destructively, meaning it will automatically generate and overwrite assets in the avatar's unique GUID folder upon every build.
To permanently generate, save, and finalize your assets so they are no longer overwritten, you must use the `Pre-Install` button located inside the Advanced Options tab.
:::

#### Better Insert Detection
- SPS plugs can now be inserted from any direction to trigger sound. Consequently, the Direction Offset menu will be removed starting from this version.
- Normalized depth values across all plug sizes for more reliable insertion and smash detection. This ensure all plug size will output more closer smash intensity value.
- Sounds now accurately trigger only while inserted (within SPS plug bending area), starting when the tip enters and stopping completely once fully withdrawn.

#### Better Blowjob Detection
- Blowjob will now trigger deep throat gagging sound based on actual depth value instead of smash intensity.

#### New Smash Logic
- Smash sounds will only trigger when the insertion depth reaches at least `55%` of the plug’s length. This change aims to improve immersion, as these sounds represent contact with the buttocks or thighs and should not occur during shallow insertion.
- Within the `55–100%` depth range, a thrust must also exceed the `10%` velocity threshold to trigger a smash sound. Slower thrusts will not trigger it.
- You can now raise the Smash Sensitivity setting slider further to make smash sounds easier to trigger.
- Smash detection now works in any direction.

#### Self-Service Update
- In VR mode, PCS will attempt to suppress sounds caused by avatar locomotion, such as joystick movement or jumping, while `Self-Service` is active. It will also try to prevent heavy smash sounds from triggering when the velocity is excessively high.
- When switching positions through the menu, the PCS target will now move instantly to the new location without interpolation (lerping), helping prevent unwanted sounds during the transition.

#### Audio Manager Tool Update
- The tool now clears all existing voice packs before applying the new one. This prevents mixing between old and new voice clips.
- Since the Voice Audio Controller is created separately, there are now two slots for you to drag and drop the respective Animator Controllers into.

#### Satisfaction & Voice Update
- Edging menu will prevent avatar from orgasm (freeze lust level at 99 points), lust will continue to increase and stop at 99.
- Gave moan voice a bit air time and delay per hit to makes it sounds more natural.
- Relax moans will now only play when there is no smash or thrust movement. Any insertion or removal during the countdown will reset the timer and restart the process.
- Brought back the legacy anime voice pack!

#### Lust System Update
- Fixed a bug that caused the Lust Manager to stop working when the Lust feature was enabled but the Voice Pack was disabled.
- Lust now syncs as an integer instead of a float to prevent decimal-value mismatches between local and remote players.
- The synced parameter has been renamed to `pcs/satisfaction/lust-int`. The original `pcs/satisfaction/lust` parameter remains available and is now synced locally to global.
- Due to this change, satisfaction events are now limited to only 10 states.

:::info Note for Creators
This new lust parameter will trigger orgasm event at 100 and will change to 101 to finalize lust logic. If you use it on your custom animation,
you may have to set the condition to be like: `Greater <99>`, not `Equal <100>`, unless you want it to be a trigger.
:::
